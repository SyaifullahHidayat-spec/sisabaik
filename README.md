## Komponen Frontend Vue 3 (Chapter 9)
**Developed by:** Syaifullah Hidayat (NIM: 23367052)

* **Versi Node.js:** v22.18.0 (sesuaikan dengan hasil `node -v` Anda)
* **Instalasi Dependency:** Jalankan `npm install` di folder `frontend`
* **Server Pengembangan (Dev):** Jalankan `npm run dev` (`http://127.0.0`)
* **Kompilasi Aplikasi (Build):** Jalankan `npm run build`
* **Preview Hasil Kompilasi:** Jalankan `npm run preview` (`http://127.0.0`)

> **Catatan:** Implementasi pada Chapter 9 ini sepenuhnya menggunakan data latihan (*fixture*) di memori RAM browser dan belum melakukan pemanggilan API ke server backend.
